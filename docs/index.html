How to read these numbers

Each file is the newest set of sales the source returned for one search, so a median covers days, not a quarter. Shipping and seller are excluded on purpose: shipping disagreed with reality by an order of magnitude on heavy lots, and seller is null on the eBay rows, so no row can be attributed. The Goodwill files do carry a seller id, which is why concentration can be checked there and not here.

Use it

Clone git clone https://github.com/silentdirectivellc-hub/ebay-sold-comps.git or read one file straight from the CSV link on its page. Corrections and new categories are welcome as pull requests.
