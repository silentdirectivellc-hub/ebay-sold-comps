What this file is not

These are the newest sales the source returned for one search, so the window is days, not the whole quarter. Shipping is not included: the source quoted less postage for a 66-piece lot than for a single item, so the field was dropped rather than published wrong. A title with a count in it but no word "lot" is still a lot, and 45 of 254 rows in one pull were misfiled that way, which moved a median 17%. Read the titles before trusting a single number. Treat a single file as a snapshot.
