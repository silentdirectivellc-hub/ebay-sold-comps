What this file is not

These are the newest sales the source returned for one search, so the window is days, not the whole quarter. Shipping is not included: the source quoted less postage for a 66-piece lot than for a single item, so the field was dropped rather than published wrong. The seller field is null on the eBay pulls, which means concentration cannot be measured: one seller running a listing series can carry a keyword. Treat a single file as a snapshot.
